# Curry Nation Website

A responsive Next.js App Router website designed for deployment on Vercel. It uses the provided Curry Nation logo and Indian folk-art references, includes page-level SEO, structured data, sitemap/robots/llms.txt, a discovery-call preference calendar, a contact API route, and two interactive self-assessments.

## Local development

1. Install Node.js 20 or later.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and set values for your environment.
4. Run `npm run dev` and open `http://localhost:3000`.
5. Run `npm run build` before deploying.

## Deploy to Vercel

1. Push this folder to a new GitHub repository.
2. Import the repository in Vercel; framework preset should be Next.js.
3. Add the environment variables below in Vercel Project Settings → Environment Variables.
4. Deploy, test the preview domain, then connect `currynation.in` in Vercel Domains and update DNS as Vercel instructs.

## Environment variables

- `NEXT_PUBLIC_SITE_URL`: canonical website URL, normally `https://currynation.in`.
- `NEXT_PUBLIC_BOOKING_URL`: optional Google Calendar appointment schedule / Calendly URL. Without it, the page collects a preferred date/time but does not reserve a live slot.
- `RESEND_API_KEY`: optional Resend API key to send contact form enquiries by email.
- `ENQUIRY_TO`: destination for enquiries (defaults to `nagesshp@currynation.in`).
- `ENQUIRY_FROM`: verified sender address/domain in Resend (defaults to `Curry Nation Website <website@currynation.in>`).

### Contact form delivery

The API route validates submissions. Without `RESEND_API_KEY`, it logs limited enquiry details server-side and returns a fallback response so the UI can be tested; it does **not** deliver email. Configure Resend and verify the sender domain before production. Never expose the API key as a `NEXT_PUBLIC_` variable.

### Booking calendar

The calendar allows users to choose a preferred weekday/date and time in IST. It is **not a live availability feed** and does not create a calendar event. To enable actual booking, configure `NEXT_PUBLIC_BOOKING_URL` with the team's Google Calendar appointment schedule or Calendly URL and review the handoff flow. For deeper integration, connect Google Calendar via a server-side OAuth flow and check availability before confirming an event.

## Editing the site

- `lib/site.ts`: page content, navigation names, company contact details and SEO defaults.
- `app/page.tsx`: home page sections and home page case/service cards.
- `app/[slug]/page.tsx`: reusable internal page template.
- `components/SiteShell.tsx`: header, navigation, intro animation and footer.
- `components/ContactExperience.tsx`: contact form and discovery-call preference calendar.
- `components/Diagnostic.tsx`: interactive Purple Cow and Brand Dependence assessments.
- `app/globals.css`: design tokens, layouts, responsive styles and animation.
- `public/assets/`: supplied logo and visual references.
- `app/sitemap.ts`, `app/robots.ts`, `public/llms.txt`: crawlability and AI discovery files.

## SEO / AI crawler notes

- `https://currynation.in/sitemap.xml` is generated by Next.js from the declared routes.
- `https://currynation.in/robots.txt` permits major crawlers listed in `app/robots.ts` and points to the sitemap. Crawler compliance is voluntary; robots.txt is not access control.
- `https://currynation.in/llms.txt` describes the site for AI systems. It does not guarantee indexing or citations.
- Structured Organization JSON-LD is emitted from `app/layout.tsx`; metadata is defined at layout and page level.
- Keep all claims, client outcomes, testimonials, and case study details approved and evidence-backed. Replace the draft Privacy Notice with legal-approved copy.

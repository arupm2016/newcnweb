# Curry Nation Website

Curry Nation website project prepared for Next.js and Vercel. This repository contains a deployment-ready starter and SEO foundation. The complete source bundle and artwork are available in the accompanying `Curry-Nation-Website-Vercel.zip`; binary artwork must be added from that bundle before this repository matches the full project.

## Local development

- Node.js 20+
- `npm install`
- Copy `.env.example` to `.env.local` and configure email/booking variables
- `npm run dev`
- `npm run build`

Import this repository into Vercel after adding the complete `public/assets` directory and remaining components from the ZIP.
